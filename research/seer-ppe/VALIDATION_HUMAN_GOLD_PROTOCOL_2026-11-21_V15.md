# SEER-PPE V15 — executable Valid-person/PPE human-gold input contract

This is the **separate Validation-only reference**; the already-reviewed but incomplete Train controls A/B/C/D are not promoted to Validation ground truth. Before scoring an approved source-independent Validation cohort, each chosen original Valid Source ID must have a genuine researcher-reviewed, dated and evidence-pinned reference record with corresponding verified Clean17 export filename.

The [empty reference overlay](VALIDATION_PERSON_PPE_SIGNED_REFERENCE_V15.json) is a future input register; do **not** fill it with model predictions, a generic assumption that all four PPE types are present, or automatically selected `UNKNOWN` values. The [executable validator](tools/validate_v15_validation_person_reference.mjs) verifies original source ID/split, exact Clean17 filename and V13 technical identity correspondence; human reviewer/date and SHA-pinned evidence note; explicit complete human person count including signed zero-person scenes; all six PPE visual states for **every** human-reviewed person; corresponding separate PPE task-mandate statuses and signed policy evidence if a mandate is claimed; valid normalized bounding boxes; independently reviewed equipment items; and owner links that cannot contradict a human `ABSENT/UNKNOWN` state. Every missing per-person `PRESENT/ABSENT/UNKNOWN` value is rejected.

A human-signed `UNKNOWN` is a valid uncertainty annotation, but a low-confidence predictor or an AI visual summary may **not** sign it. Missing workers do **not** become zero-person scenes merely because the detector found none. A person–gear association may be `UNKNOWN` without an owner; an owner may not be guessed.

This gold validator is **separate from source-family independence** and from the frozen model evaluation bundle. Signed Validation reference alone does not clear source holds, the six V14 overlap quarantines, source-site dependence, task PPE compliance mandates or freeze policy. The overlay currently contains **0 human-signed Valid records**, and `scoring_ready=false`. Tests are synthetic only and do not create scientific model metrics. No Test images have been read for this work.
