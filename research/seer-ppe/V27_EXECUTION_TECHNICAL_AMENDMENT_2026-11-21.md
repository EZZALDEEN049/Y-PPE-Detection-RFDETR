# V27 execution amendment — supported Workflow detection-property filters

**21 November 2026, before any returned occlusion result.** This amendment preserves the exact nine images, ten frozen target boxes, A5/A6 selection, controls, model, confidence/NMS thresholds, blur kernel and budgets in the V27 protocol and target manifest. It changes only the Workflow target-filter implementation after the first no-result execution attempt.

## Observed preflight failure

The first inline Workflow validation passed, but the first execution failed in the `DetectionsFilter` stage at the first `width >=` query. The Roboflow Workflow query engine returned `None` for `ExtractDetectionProperty(width)` on this model output, so the comparison with a numeric threshold failed. The same limitation applies to `height`. The error occurred after the initial baseline model block was entered and before the target-blur or post-occlusion model block produced a result. Treat this as one technical preflight baseline-inference attempt; no target-occlusion XAI result exists from it.

## Frozen correction — do not widen after outcomes

The executable target filter now uses only supported properties:

- Exact `class_name`.
- Confidence in the original saved target confidence ±0.08, bounded below by 0.20 and above by 1.0.
- Four original-image box edges `x_min`, `x_max`, `y_min`, and `y_max`, each within `max(6 px, round(1% of the smaller original image dimension))` of the frozen V25 edge.

The four edge windows jointly constrain both box position and width/height; separate `width` and `height` extraction statements are removed because they return null in this engine. No confidence or coordinate tolerance may be widened in response to an observed target. The filter must still return **exactly one** target (and exactly one control when a control is specified), or that target workflow fails closed.

## Unchanged items

- Nine source images and their Source Asset IDs; 10 unique target IDs and their A5/A6 memberships; seven non-overlap control IDs.
- A5 unchanged; A6 unchanged: `0.50*(1-confidence)+0.30*class_FDR+0.20*unresolved_association`, with FDR calibrated on V26 M0 minus the five V23 pilot images.
- Original RF-DETR Small model `altayyar-0oflt-lafos-qqauz/2`, custom confidence 0.20, NMS overlap 0.50, Active Learning disabled.
- BlurVisualization kernel 51 and padding 5; target and control branches; one target slot per image per arm.
- The planned 27 original-model passes for the ten unique target workflows. The failed preflight baseline attempt is separately logged and is not counted as an A5/A6 target outcome.
- No Test access, model training, original image/annotation/split changes, human-review dispatch, worker compliance inference or Joules claim.

The exact corrected Workflow specs are regenerated by `tools/build_v27_occlusion_specs.mjs` and stored in `V27_FROZEN_OCCLUSION_WORKFLOW_SPECS_2026-11-21.json`. The target manifest itself is not changed.
