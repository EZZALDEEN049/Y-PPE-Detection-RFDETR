## Original unchanged predictor and frozen scoring criteria
- Model **fixed** `altayyar-0oflt-lafos-qqauz/2` (RF-DETR Small, 17 original classes), hosted `models_infer` with `confidence=0.20`, `overlap=0.50`. Same Source original image HTTPS URL obtained privately through `images_workspace_search`; NEVER store URLs, original image pixels or tokens in GitHub.
- Predicted original-space bounding boxes and annotated current Source original-space bounding boxes use `center(x,y), width, height` pixel representation and the **same unmodified Source width/height**. Finite positive dimensions, existing exact class vocabulary, distinct predicted IDs and native input-image ID must be checked. Inference must report exact resolved model ID and image dimensions; otherwise the image is `FAIL_CLOSED`, not scored.
- **Per-image, class-exact one-to-one greedy matching**: sort predictions by descending confidence (then stable prediction ID), select highest-IoU unused GT of identical label class; match if bounded-bbox intersection-over-union **≥0.50**. Each prediction and reference can match at most once. TP = matches, FP = unmatched predicted boxes, FN = unmatched original current annotation boxes. Keep exact per-class 17-category TP/FP/FN and per-image counts. Clip bounding boxes to original image area as in V23; reject degenerate/invalid boxes. Count and provenance conservation must hold.
- Micro precision `TP/(TP+FP)`; micro recall `TP/(TP+FN)`; micro F1 `2TP/(2TP+FP+FN)`; per-class analogues with undefined denominators `null`. **Do not call this COCO mAP**; this is a fixed IoU0.50 object-match diagnostic, NOT safety compliance or occupational PPE. The negative-name classes (`No Face Mask`, etc.) are detector objects, not verified task-policy violations.
